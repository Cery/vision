# Vision NDT 服务器使用说明

## 📋 概述

Vision NDT项目包含两个主要服务器：
1. **Hugo开发服务器** (端口1313) - 主要网站服务
2. **Express API服务器** (端口3002) - 后端API和工具服务

## 🚀 服务器启动

### 1. Hugo开发服务器 (推荐)
```bash
# 在项目根目录执行
hugo server -D --bind 0.0.0.0 --port 1313

# 访问地址
http://localhost:1313
```

**功能特点：**
- ✅ 完整的网站功能
- ✅ 热重载开发
- ✅ 所有工具页面可用
- ✅ 静态资源服务
- ✅ Markdown内容渲染

### 2. Express API服务器 (辅助)
```bash
# 在项目根目录执行
node simple-server.js

# 访问地址
http://localhost:3002
```

**功能特点：**
- ✅ API接口服务
- ✅ 内容管理后端
- ✅ 文件上传下载
- ✅ 数据统计接口

## 🔧 正确使用方法

### 推荐工作流程

1. **启动Hugo服务器** (主要服务)
   ```bash
   hugo server -D --bind 0.0.0.0 --port 1313
   ```

2. **启动Express服务器** (API支持)
   ```bash
   node simple-server.js
   ```

3. **访问主网站**
   ```
   http://localhost:1313
   ```

4. **使用管理工具**
   - 内容管理：http://localhost:1313/tools/content-manager.html
   - AI工具测试：http://localhost:1313/tools/ai-test.html

### 内容管理系统使用

1. **访问内容管理器**
   ```
   http://localhost:1313/tools/content-manager.html
   ```

2. **功能说明**
   - **仪表板**：查看内容统计和概览
   - **新闻管理**：管理技术文章、行业资讯、展会信息
   - **产品管理**：管理产品信息，按供应商分类
   - **案例管理**：管理应用案例
   - **供应商管理**：管理供应商信息
   - **需求管理**：查看和管理客户需求

3. **操作流程**
   - 选择内容类型
   - 点击"新建"创建内容
   - 使用编辑器编写内容
   - 点击"保存"保存到对应目录
   - 支持预览、编辑、删除操作

### AI工具使用

1. **配置检查**
   ```
   http://localhost:1313/tools/ai-test.html
   ```

2. **AI功能**
   - OpenRouter API已配置密钥
   - 支持自动内容生成
   - 支持智能图片处理
   - 支持多种内容类型

3. **编辑器使用**
   - 展会编辑器：自动生成展会信息
   - 技术文章编辑器：生成技术文章
   - 新闻编辑器：生成行业新闻
   - 案例编辑器：生成应用案例

## 🐛 常见问题解决

### 1. 端口占用问题
```bash
# 检查端口占用
netstat -ano | findstr :1313
netstat -ano | findstr :3002

# 终止占用进程
taskkill /PID [进程ID] /F
```

### 2. 服务器无法访问
- **检查防火墙设置**
- **确认服务器已启动**
- **检查端口是否正确**
- **尝试使用127.0.0.1替代localhost**

### 3. API接口错误
- **确保Express服务器运行**
- **检查API地址是否正确**
- **查看浏览器控制台错误信息**

### 4. 内容保存失败
- **确保有写入权限**
- **检查目录是否存在**
- **确认API服务器正常运行**
