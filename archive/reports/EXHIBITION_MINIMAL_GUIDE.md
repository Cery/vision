# 极简展会资讯模板使用指南

## 📋 设计理念

根据您的要求，我们创建了极简的展会资讯模板，特点：
- **纯文本内容**：MD文件中不使用任何标题标记（#、##、###）
- **简洁介绍**：只对展会本身做基本介绍，无需特别详细
- **样式分离**：所有样式在HTML模板中定义
- **统一格式**：确保所有展会页面视觉一致

## 📝 内容编写规范

### ✅ 推荐格式
```markdown
展会名称是专业的行业展览会，创办于XXXX年，每年/两年举办一届。展会汇聚全球主要企业，展示最新技术和产品。展会设有多个专业展区，同期举办新产品发布会和技术论坛。作为行业重要展览会，为企业提供展示平台和商务合作机会。
```

### ❌ 避免使用
- 标题标记：`# ## ###`
- 加粗样式：`**文本**`
- 斜体样式：`*文本*`
- HTML标签：`<strong>文本</strong>`
- 复杂结构：多层级内容组织

### 📏 内容长度建议
- **总字数**：100-200字
- **段落数**：1-2段
- **句子长度**：简洁明了，避免过长

## 🚀 快速使用方法

### 步骤1：复制极简模板
```bash
cp content/news/exhibition-template-minimal.md content/news/your-exhibition.md
```

### 步骤2：修改基本信息
```yaml
---
title: "2025年北京国际汽车展览会"
summary: "中国最大的汽车展览会，展示全球最新汽车技术"
date: 2025-07-12T10:00:00+08:00
draft: false
layout: "exhibition-universal"

# 展会基本信息
event_date: "2025年4月25日~5月4日"
location: "中国国际展览中心"
organizer: "中国汽车工业协会"
exhibition_type: "国际专业展"
---
```

### 步骤3：编写简洁介绍
```markdown
北京国际汽车展览会是中国最大的汽车展览会，创办于1990年，每两年举办一届。展会汇聚全球主要汽车制造商和零部件供应商，展示最新的汽车技术和产品。展会设有乘用车、新能源汽车、商用车、汽车零部件等专业展区，同期举办多场新车发布会和技术论坛。
```

## 🎨 显示效果

### 页面结构
1. **展会信息看板**：封面图、基本信息、倒计时
2. **展会介绍**：简洁的文字介绍（来自MD文件内容）
3. **展品范围**：分类展示（来自Front Matter）
4. **往届回顾**：图片展示（来自Front Matter）
5. **往届参展商**：名称列表（来自Front Matter）
6. **右侧边栏**：相关展会、推荐产品

### 内容样式
- **首段突出**：第一段文字加粗显示，无缩进
- **段落缩进**：后续段落自动首行缩进2字符
- **字体优化**：使用1.1rem字号，1.8倍行高
- **对齐方式**：两端对齐，提升阅读体验

## 🔧 自定义配置

### 修改展品范围
```yaml
exhibition_scope:
  - category: "主要产品类别1"
    items:
      - "产品1"
      - "产品2"
      - "产品3"
  - category: "主要产品类别2"
    items:
      - "产品A"
      - "产品B"
      - "产品C"
```

### 添加参展商
```yaml
previous_exhibitors:
  - name: "知名企业1"
  - name: "知名企业2"
  - name: "知名企业3"
  # 建议10-20家代表性企业
```

### 设置相关产品
```yaml
related_products:
  - "产品型号1"
  - "产品型号2"
  # 链接到相关的产品页面
```

## 🚀 发布流程

### 1. 准备工作
- 收集展会基本信息（时间、地点、主办方等）
- 准备封面图片和历届图片
- 整理主要参展商名单
- 确定展品分类

### 2. 创建文件
- 复制极简模板文件
- 修改文件名（建议格式：年份-展会简称.md）
- 更新Front Matter信息
- 编写1-2段简洁介绍

### 3. 内容检查
- 确认无任何标题标记（#）
- 确认无加粗、斜体等样式
- 检查内容长度适中（100-200字）
- 验证信息准确性

### 4. 发布上线
- 设置`draft: false`
- 本地预览效果
- 提交版本控制
- 部署到生产环境

## 📞 常见问题

### Q: 内容太短会不会影响SEO？
A: 不会。重要信息都在Front Matter中，搜索引擎可以正常抓取。简洁的内容反而提升用户体验。

### Q: 可以添加图片吗？
A: 可以。在Front Matter中配置`cover`和`historical_images`，图片会自动显示在相应位置。

### Q: 如何突出重点信息？
A: 重点信息应该放在Front Matter的相应字段中，如`summary`、`exhibition_scope`等，模板会自动突出显示。

### Q: 内容可以分段吗？
A: 可以。使用空行分段，模板会自动处理段落样式，首段突出显示，后续段落自动缩进。
