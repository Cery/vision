# 展会看板封面图优化说明

## 🎯 优化目标

根据您的要求，我们对展会看板中的封面图进行了按比例增大的优化，并设置了合适的边距：

- **尺寸增大**：按比例增大封面图，提升视觉冲击力
- **边距优化**：上下左侧各留5px边距，右侧与文字保持合适间距
- **响应式适配**：各种设备都有相应的尺寸优化
- **布局协调**：确保与整体看板布局协调统一

## 📐 尺寸调整详情

### 桌面端 (1024px+)
```css
.exhibition-logo {
    width: 220px;    /* 之前: 160px → 现在: 220px (+37.5%) */
    height: 190px;   /* 之前: 140px → 现在: 190px (+35.7%) */
    margin: 5px 5px 5px 0;  /* 上右下左边距 */
}
```

**改进效果：**
- **宽度增加**：37.5%的增幅，更加突出
- **高度增加**：35.7%的增幅，保持良好比例
- **边距设置**：上下左侧5px，右侧5px与文字分隔

### 平板端 (768px-1024px)
```css
.exhibition-logo {
    width: 180px;    /* 之前: 140px → 现在: 180px (+28.6%) */
    height: 150px;   /* 之前: 120px → 现在: 150px (+25%) */
    margin: 5px;     /* 四周5px边距 */
}
```

**改进效果：**
- **适中增大**：在平板设备上保持合适的视觉比例
- **统一边距**：四周5px边距，简洁统一

### 手机端 (768px以下)
```css
.exhibition-logo {
    width: 150px;    /* 之前: 120px → 现在: 150px (+25%) */
    height: 120px;   /* 之前: 100px → 现在: 120px (+20%) */
    margin: 5px;     /* 四周5px边距 */
}
```

**改进效果：**
- **合理增大**：在小屏幕上仍然保持清晰可见
- **比例协调**：与手机屏幕尺寸协调

### 超小屏幕 (576px以下)
```css
.exhibition-logo {
    width: 130px;    /* 之前: 100px → 现在: 130px (+30%) */
    height: 100px;   /* 之前: 80px → 现在: 100px (+25%) */
    margin: 5px;     /* 四周5px边距 */
}
```

**改进效果：**
- **最小可用尺寸**：确保在最小屏幕上仍然清晰
- **保持可读性**：不会过大影响其他内容显示
