## ✅ 任务2：移除按钮改为图片链接

### 🎯 问题描述
资讯中心列表和案例列表中的"阅读全文"、"查看详情"按钮需要去掉，改为图片按钮链接。

### 🛠️ 解决方案

#### **资讯中心列表优化**
**修改前**：
```html
<div class="card-img-overlay d-flex align-items-end">
    <div class="w-100 text-end mb-3">
        <a href="..." class="btn btn-primary btn-sm">阅读全文</a>
    </div>
</div>
```

**修改后**：
```html
<a href="..." class="image-link">
    <img src="..." class="card-img-top object-fit-cover" alt="...">
</a>
```

#### **案例列表优化**
**修改前**：
```html
<div class="card-img-overlay d-flex align-items-end">
    <div class="w-100 text-end mb-3">
        <a href="..." class="btn btn-primary btn-sm">查看详情</a>
    </div>
</div>
```

**修改后**：
```html
<a href="..." class="image-link">
    <img src="..." class="card-img-top object-fit-cover" alt="...">
</a>
```

#### **视觉效果增强**

```css
/* 图片链接样式 */
.card-img-wrapper .image-link {
    display: block;
    text-decoration: none;
    position: relative;
    overflow: hidden;
}

/* 悬停效果 */
.card-img-wrapper .image-link::after {
    content: '';
    position: absolute;
    top: 0;
    left: 0;
    right: 0;
    bottom: 0;
    background: rgba(0, 0, 0, 0.3);
    opacity: 0;
    transition: opacity 0.15s ease-in-out;
}

/* 悬停时显示遮罩 */
.news-card:hover .card-img-wrapper .image-link::after {
    opacity: 1;
}

/* 图片缩放效果 */
.news-card:hover .card-img-top {
    transform: scale(1.05);
}
```

### 🎨 用户体验改进
- **整个图片可点击**：增大点击区域，提升可用性
- **悬停视觉反馈**：图片缩放 + 半透明遮罩
- **平滑过渡动画**：0.15s缓动效果
- **无障碍访问**：保持语义化链接结构
