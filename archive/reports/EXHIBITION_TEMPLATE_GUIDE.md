# 展会资讯模板使用指南

## 📋 概述

本指南介绍如何使用展会资讯模板系统，该系统将样式定义与内容分离，确保：
- **模板定义样式**：所有样式、布局、交互功能在模板中定义
- **MD文件纯内容**：Markdown文件只包含结构化数据和纯文本内容
- **统一视觉效果**：所有展会资讯页面保持一致的设计风格

## 🎨 模板文件

### 1. 主模板文件
- **文件位置**：`layouts/news/exhibition-simple.html`
- **功能**：定义展会资讯页面的完整布局、样式和交互功能
- **特点**：
  - 响应式设计，适配各种设备
  - 内置倒计时功能
  - 图片画廊展示
  - 社交分享功能
  - 浏览量统计

### 2. 内容模板文件
- **文件位置**：`content/news/exhibition-template-clean.md`
- **功能**：提供标准的展会资讯内容结构
- **特点**：
  - 完整的Front Matter配置
  - 标准化的内容结构
  - 详细的字段说明

## 📝 创建新的展会资讯

### 步骤1：复制模板文件
```bash
cp content/news/exhibition-template-clean.md content/news/your-exhibition-name.md
```

### 步骤2：修改Front Matter
编辑文件头部的YAML配置：

**⚠️ 重要提醒：内容编写规范**
- ✅ 使用纯文本，不添加任何Markdown样式
- ❌ 不使用 `**加粗**` 语法
- ❌ 不使用 `*斜体*` 语法
- ❌ 不添加HTML标签
- ✅ 所有样式由模板自动处理

```yaml
---
title: "2025年中国国际工业博览会"
summary: "亚洲最大的工业展览会，展示最新工业技术和设备"
date: 2025-07-12T10:00:00+08:00
publishDate: 2025-07-12T10:00:00+08:00
draft: false  # 改为false发布
categories: ["展会信息"]
tags: ["工业博览会", "制造业", "自动化"]
layout: "exhibition-simple"  # 使用简洁模板

# 展会基本信息
event_date: "2025年9月15日~9月19日"
opening_hours: "09:00 - 17:00"
location: "国家会展中心（上海）"
detailed_location: "中国 - 上海 - 青浦区崧泽大道333号"
organizer: "中国机械工业联合会"
exhibition_industry: "工业制造"
exhibition_type: "国际专业展"

# 展会规模
cycle: "一年一届"
exhibition_area: "280000平方米"
exhibitor_count: "2800家"
visitor_count: "180000人"

# 封面图片
cover: "/images/news/ciif-2025-cover.jpg"
featured_image: "/images/news/ciif-2025-cover.jpg"
---
```

### 步骤3：编辑展品范围
```yaml
exhibition_scope:
  - category: "智能制造装备"
    items:
      - "工业机器人"
      - "数控机床"
      - "3D打印设备"

  - category: "工业软件"
    items:
      - "MES系统"
      - "ERP软件"
      - "CAD/CAM软件"
      - "仿真软件"
      - "工业互联网平台"
```

### 步骤4：添加联系信息
```yaml
contact_info:
  phone: "+86-21-22068888"
  email: "info@ciif-expo.com"
  website: "https://www.ciif-expo.com"

registration_info:
  deadline: "2025年8月31日"
  fee: "根据展位面积确定"
  url: "https://www.ciif-expo.com/register"
```

### 步骤5：编写正文内容
在Front Matter之后编写展会的详细介绍，**严格遵循无样式原则**：

```markdown
## 展会背景

中国国际工业博览会（CIIF）创办于1999年，是由国家发展和改革委员会、商务部、工业和信息化部等国家部委和上海市人民政府共同主办的国家级、国际性、专业化的大型展览会。

## 展会特色

### 规模宏大
展会总面积达28万平方米，参展企业超过2800家，专业观众超过18万人次。

### 技术先进
汇聚全球最新的工业技术和设备，展示工业4.0和智能制造的最新成果。
```

**📝 内容编写要点：**
- 只使用标题（#、##、###）来组织结构
- 使用无序列表（-）来列举要点
- 所有文本保持纯文本格式
- 让模板自动处理所有视觉样式

## 🔧 自定义配置

### 修改颜色主题
在模板的CSS部分修改颜色变量：

```css
:root {
    --primary-color: #667eea;    /* 主色调 */
    --secondary-color: #764ba2;  /* 辅助色 */
    --accent-color: #ffc107;     /* 强调色 */
}
```

### 添加新的展品分类图标
在模板中为不同的展品分类添加对应图标：

```html
{{ if eq .category "智能制造" }}
<i class="bi bi-robot me-2 text-primary"></i>
{{ else if eq .category "工业软件" }}
<i class="bi bi-code-square me-2 text-success"></i>
{{ else }}
<i class="bi bi-box me-2 text-secondary"></i>
{{ end }}
```

### 自定义倒计时样式
修改倒计时的显示样式和动画效果：

```css
.countdown-number {
    font-size: 2.5rem;
    font-weight: 700;
    color: #ffffff;
    text-shadow: 2px 2px 4px rgba(0,0,0,0.5);
}
```

## 🧹 样式清理指南

### 清理现有文件中的样式

如果您有包含样式的现有展会文件，需要清理以符合模板要求：

#### 1. 清理加粗样式
```bash
# 查找包含加粗样式的文件
grep -r "\*\*.*\*\*" content/news/

# 手动清理或使用编辑器批量替换
# 将 **文本** 替换为 文本
```

#### 2. 清理斜体样式
```bash
# 查找包含斜体样式的文件
grep -r "\*.*\*" content/news/

# 将 *文本* 替换为 文本
```

#### 3. 清理HTML标签
```bash
# 查找包含HTML标签的文件
grep -r "<.*>" content/news/

# 移除所有HTML标签
```

#### 4. 验证清理结果
```bash
# 确保文件只包含纯文本和基本Markdown结构
# 允许的格式：
# - 标题：# ## ###
# - 列表：- 项目
# - 段落：纯文本
# - 链接：[文本](URL)
```

### 样式清理检查清单

- [ ] 移除所有 `**加粗**` 语法
- [ ] 移除所有 `*斜体*` 语法
- [ ] 移除所有HTML标签
- [ ] 保留标题结构（#、##、###）
- [ ] 保留列表结构（-）
- [ ] 保留链接格式（[文本](URL)）
- [ ] 确保Front Matter完整正确

## 📱 最佳实践

### 1. 图片优化
- 封面图片建议尺寸：1200x600px
- 历届图片建议尺寸：800x600px
- 使用WebP格式以获得更好的加载性能
- 为所有图片添加alt属性

### 2. 内容编写
- 标题简洁明了，突出展会特色
- 摘要控制在100字以内
- 正文使用清晰的层级结构
- 避免在Markdown中添加HTML样式

### 3. SEO优化
- 填写完整的SEO信息
- 使用相关的行业关键词
- 保持URL结构的一致性
- 添加结构化数据标记

### 4. 性能优化
- 压缩图片文件大小
- 使用CDN加速图片加载
- 启用浏览器缓存
- 优化JavaScript执行
