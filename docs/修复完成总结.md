### 1.4 数据一致性检查 ✅

**新增API**: `GET /api/admin/consistency-check`

**检查内容**:
1. **产品-供应商关联一致性**
   - 检查所有产品的supplier_id是否有效
   - 列出孤立产品（supplier_id不存在）

2. **报价-需求关联一致性**
   - 检查所有报价的requirement_id是否有效
   - 列出孤立报价（requirement_id不存在）

3. **案例-产品关联一致性**
   - 检查所有案例的related_product_id是否有效
   - 列出孤立案例（related_product_id不存在）

**返回格式**:
```json
{
  "ok": true,
  "checks": {
    "products": { "total": 100, "withSupplier": 95, "orphaned": [...] },
    "quotes": { "total": 200, "valid": 195, "orphaned": [...] },
    "cases": { "total": 50, "withProduct": 48, "orphaned": [...] }
  },
  "hasIssues": true,
  "summary": { ... }
}
```
