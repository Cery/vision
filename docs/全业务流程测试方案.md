## 一、测试环境准备

### 1.1 本地开发环境

**启动服务**:
```bash
# 1. 启动Hugo开发服务器
cd /path/to/vision
hugo server -D --port 1313

# 2. 启动Cloudflare Workers本地开发
cd cloudflare
wrangler dev --port 8787

# 3. 配置API地址
# 在浏览器控制台或localStorage设置：
localStorage.setItem('API_BASE', 'http://localhost:8787')
```

**访问地址**:
- 前端: `http://localhost:1313`
- API: `http://localhost:8787`
- 管理后台: `http://localhost:1313/admin/dashboard.html`

### 1.2 生产环境

**部署流程**:
1. 提交代码到Git仓库
2. Netlify自动触发构建和部署
3. Cloudflare Workers自动部署（如果配置了CI/CD）

**访问地址**:
- 前端: `https://www.visndt.com`
- API: `https://api.visndt.com`
- 管理后台: `https://www.visndt.com/admin/dashboard.html`

## 二、测试用例

### 测试用例1: 发布产品

#### 1.1 通过管理后台发布

**步骤**:
1. 登录管理后台: `/admin/dashboard.html`
2. 点击"内容管理" → 进入内容管理器
3. 选择"产品管理"
4. 点击"新建产品"
5. 填写产品信息：
   ```
   产品名称: 测试产品-001
   产品型号: TEST-001
   产品系列: Test Series
   主分类: 电子内窥镜
   次分类: 工业视频内窥镜
   摘要: 这是一个测试产品
   详细描述: 详细的产品描述内容...
   SEO标题: 测试产品-001 | Vision NDT
   SEO关键词: 测试,产品,内窥镜
   SEO描述: 测试产品描述
   ```
6. 上传封面图片
7. 添加产品参数
8. 保存产品

**验证点**:
- [ ] 产品保存成功
- [ ] 产品出现在产品列表中
- [ ] 前端产品页面可以访问
- [ ] SEO信息正确显示
- [ ] 图片正常显示

#### 1.2 通过API发布

```bash
# 登录获取Token
TOKEN=$(curl -X POST http://localhost:8787/api/admin/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"password"}' \
  | jq -r '.token')

# 发布产品
curl -X POST http://localhost:8787/api/admin/products \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "API测试产品",
    "model": "API-TEST-001",
    "series": "API Series",
    "primary_category": "电子内窥镜",
    "summary": "通过API创建的产品",
    "status": "published"
  }'
```

**验证点**:
- [ ] API返回成功
- [ ] 产品ID已生成
- [ ] 产品出现在列表中

### 测试用例2: 发布新闻

#### 2.1 通过管理后台发布

**步骤**:
1. 进入内容管理器
2. 选择"新闻管理"
3. 点击"新建新闻"
4. 填写新闻信息：
   ```
   标题: 测试新闻-001
   分类: 技术文章
   摘要: 这是测试新闻摘要
   内容: 新闻正文内容...
   标签: 测试,技术
   作者: 测试作者
   SEO信息: ...
   ```
5. 设置发布状态为"已发布"
6. 保存

**验证点**:
- [ ] 新闻保存成功
- [ ] 新闻出现在新闻列表中
- [ ] 前端新闻页面可以访问
- [ ] 新闻分类正确
- [ ] 标签正确显示

#### 2.2 通过静态文件发布

**步骤**:
1. 在`content/news/`目录创建Markdown文件
2. 添加Front Matter：
   ```yaml
   ---
   title: "静态文件测试新闻"
   date: 2025-01-20
   category: "技术文章"
   tags: ["测试"]
   draft: false
   ---
   ```
3. 保存文件
4. Hugo自动重新构建
5. 同步到数据库：
   ```bash
   POST /api/admin/import-news?base=http://localhost:1313/data
   ```

**验证点**:
- [ ] 静态文件被Hugo识别
- [ ] 索引文件生成正确
- [ ] 同步到数据库成功
- [ ] 前端可以访问

### 测试用例5: 需求审核与管理

#### 5.1 审核需求

**步骤**:
1. 登录管理后台
2. 进入需求管理: `/admin/tools/requirements-admin.html`
3. 找到待审核需求
4. 点击"详情"
5. 设置审核状态：
   - 审批状态: 已通过
   - 状态: 公开
   - 进度: 发布中
6. 保存

**验证点**:
- [ ] 需求状态更新成功
- [ ] 前端需求列表显示该需求
- [ ] 需求详情页可以访问

#### 5.2 需求撮合

**步骤**:
1. 在需求详情页点击"撮合供应商"
2. 或通过API：
   ```bash
   curl -X POST http://localhost:8787/api/admin/match-suppliers \
     -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"requirement_id": "REQ-xxx"}'
   ```
3. 查看匹配结果

**验证点**:
- [ ] 返回匹配的供应商列表
- [ ] 匹配分数合理
- [ ] 匹配关键词正确

### 测试用例6: 供应商报价

#### 6.1 供应商查看需求

**步骤**:
1. 访问需求详情页: `/view.html?id=REQ-xxx&password=xxx`
2. 或通过API：
   ```bash
   curl "http://localhost:8787/api/markets/REQ-xxx?supplier_access_password=888888"
   ```
3. 查看需求详情

**验证点**:
- [ ] 可以查看需求基本信息
- [ ] 使用供应商密码可以查看联系方式
- [ ] 报价表单可以显示

#### 6.2 提交报价

**步骤**:
1. 在需求详情页填写报价表单：
   ```
   供应商名称: 测试供应商
   联系电话: 13700137000
   报价金额: 150000
   货币: CNY
   备注: 这是测试报价
   ```
2. 如果需求开启了"开放报价"，直接提交
3. 如果未开启，需要提供报价密码

**验证点**:
- [ ] 报价提交成功
- [ ] 返回报价ID
- [ ] 报价出现在报价列表中
- [ ] 需求方可以查看报价

#### 6.3 通过API提交报价

```bash
curl -X POST http://localhost:8787/api/quotes \
  -H "Content-Type: application/json" \
  -d '{
    "requirement_id": "REQ-xxx",
    "supplier_name": "API测试供应商",
    "supplier_phone": "13600136000",
    "amount": 200000,
    "currency": "CNY",
    "remarks": "API测试报价",
    "supplier_access_password": "888888"
  }'
```

**验证点**:
- [ ] API返回成功
- [ ] 报价ID已生成
- [ ] 报价状态为"已提交"

### 测试用例8: 数据同步测试

#### 8.1 静态站点到数据库同步

**步骤**:
1. 在`content/`目录创建/修改内容文件
2. 运行Hugo构建: `hugo --minify`
3. 检查索引文件: `/data/index.json`
4. 调用同步API：
   ```bash
   # 同步产品
   curl -X POST "http://localhost:8787/api/admin/import-products?base=http://localhost:1313/data" \
     -H "Authorization: Bearer $TOKEN"
   
   # 同步新闻
   curl -X POST "http://localhost:8787/api/admin/import-news?base=http://localhost:1313/data" \
     -H "Authorization: Bearer $TOKEN"
   
   # 同步案例
   curl -X POST "http://localhost:8787/api/admin/import-cases?base=http://localhost:1313/data" \
     -H "Authorization: Bearer $TOKEN"
   ```

**验证点**:
- [ ] 索引文件生成正确
- [ ] 同步API返回成功
- [ ] 数据库中有对应记录
- [ ] 同步元数据已更新

#### 8.2 数据库到前端同步

**步骤**:
1. 通过管理后台创建内容
2. 检查前端API：
   ```bash
   # 产品列表
   curl "http://localhost:1313/api/products"
   
   # 新闻列表
   curl "http://localhost:1313/api/news"
   
   # 案例列表
   curl "http://localhost:1313/api/cases"
   ```

**验证点**:
- [ ] API返回数据
- [ ] 数据格式正确
- [ ] 前端页面显示正确

#### 8.3 数据一致性验证

**步骤**:
1. 对比静态索引和数据库数据
2. 检查字段映射是否正确
3. 验证数据完整性

**验证点**:
- [ ] 静态索引和数据库数据一致
- [ ] 字段映射正确
- [ ] 无数据丢失
