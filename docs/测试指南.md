# Vision NDT 全业务流程测试指南

**版本**: 1.0  
**更新日期**: 2025-01-XX

---

## 一、测试概述

### 1.1 测试目标

验证以下业务流程的完整性和正确性：
1. 内容发布流程（产品、新闻、案例）
2. 需求市场流程（发布需求、供应商注册、报价）
3. 数据同步流程（管理后台与前端数据一致性）
4. 管理功能流程（数据备份、报表、日志）

### 1.2 测试环境

- **本地开发环境**: `http://localhost:8787` (API), `http://localhost:1313` (前端)
- **生产环境**: `https://api.visndt.com` (API), `https://www.visndt.com` (前端)

### 2.1 环境检查


### 2.2 配置检查

**环境变量配置**:
```bash
# Cloudflare Workers环境变量
ADMIN_USER=your_username
ADMIN_PASSWORD=your_password
JWT_SECRET=your_jwt_secret
ADMIN_KEY=your_admin_key
```

**本地测试配置**:
- 确保本地数据库（D1）已初始化
- 确保R2存储已配置（可选）

## 三、测试执行

### 3.1 使用测试脚本

#### Node.js脚本
```bash
# 测试本地环境
node scripts/test-full-workflow.js local

# 测试生产环境
node scripts/test-full-workflow.js production

# 测试所有环境
node scripts/test-full-workflow.js all
```

#### PowerShell脚本
```powershell
# 测试本地环境
.\scripts\test-workflow.ps1 -Environment local

# 测试生产环境
.\scripts\test-workflow.ps1 -Environment production

# 测试所有环境
.\scripts\test-workflow.ps1 -Environment all

# 自定义API地址
.\scripts\test-workflow.ps1 -Environment local -ApiBase "http://localhost:8787" -FrontendBase "http://localhost:1313"

# 自定义管理员账号
.\scripts\test-workflow.ps1 -Environment local -AdminUser "admin" -AdminPassword "password"
```

### 3.2 手动测试步骤

#### 步骤1: 管理员登录
1. 访问管理后台：`/admin/dashboard.html`
2. 输入管理员账号和密码
3. 验证登录成功，获取Token

#### 步骤2: 发布产品
1. 进入内容管理器
2. 选择"产品管理"
3. 点击"新建"
4. 填写产品信息：
   - 名称：测试产品-{时间戳}
   - 型号：TEST-001
   - 分类：电子内窥镜
   - 状态：active
5. 保存并验证产品出现在列表中

#### 步骤3: 发布新闻
1. 进入内容管理器
2. 选择"新闻管理"
3. 创建新闻：
   - 标题：测试新闻-{时间戳}
   - 分类：技术文章
   - 状态：published
4. 保存并验证

#### 步骤4: 发布案例
1. 进入内容管理器
2. 选择"案例管理"
3. 创建案例：
   - 标题：测试案例-{时间戳}
   - 行业：航空航天
   - 状态：published
4. 保存并验证

#### 步骤5: 发布需求
1. 访问需求发布页面：`/publish.html`
2. 填写需求信息：
   - 标题：测试需求-{时间戳}
   - 分类：电子内窥镜
   - 联系人信息
   - 状态：公开
3. 提交并记录返回的需求ID和密码

#### 步骤6: 供应商注册
1. 访问供应商入口：`/entry-supplier.html`
2. 填写供应商信息：
   - 公司名称：测试供应商公司-{时间戳}
   - 联系人信息
3. 提交注册

#### 步骤7: 提交报价
1. 访问需求详情页（使用需求ID和密码）
2. 填写报价信息：
   - 金额：10000
   - 货币：CNY
   - 备注：测试报价
3. 提交报价

#### 步骤8: 验证前端数据
1. 访问产品列表页：`/products`
2. 验证新创建的产品显示
3. 访问新闻列表页：`/news`
4. 验证新创建的新闻显示
5. 访问案例列表页：`/cases`
6. 验证新创建的案例显示
7. 访问需求市场：`/markets`
8. 验证新发布的需求显示

#### 步骤9: 验证管理后台数据
1. 登录管理后台
2. 查看统计仪表板，验证数据统计正确
3. 查看需求列表，验证新需求存在
4. 查看报价列表，验证新报价存在
5. 测试数据导出功能

#### 步骤10: 测试数据同步
1. 在管理后台执行数据同步：
   ```bash
   POST /api/admin/import-products?base=https://www.visndt.com/data
   POST /api/admin/import-news?base=https://www.visndt.com/data
   POST /api/admin/import-cases?base=https://www.visndt.com/data
   ```
2. 验证同步结果
3. 检查同步元数据

## 五、测试结果验证

### 5.1 成功标准

所有测试用例应满足：
1. ✅ API返回正确的HTTP状态码（200/201）
2. ✅ 返回数据格式正确
3. ✅ 前端页面正确显示数据
4. ✅ 管理后台数据与前端一致
5. ✅ 操作日志正确记录

### 5.2 常见问题

#### 问题1: 登录失败
**原因**: 
- 账号密码错误
- Token过期
- 环境变量未配置

**解决**:
- 检查环境变量配置
- 重新登录获取新Token
- 检查用户状态是否为active

#### 问题2: 数据不同步
**原因**:
- 静态站点未重新构建
- 同步API未执行
- 数据库连接问题

**解决**:
- 手动触发Hugo构建
- 执行同步API
- 检查数据库连接

#### 问题3: 前端数据为空
**原因**:
- API未返回数据
- 前端请求失败
- 数据未同步

**解决**:
- 检查API响应
- 查看浏览器控制台错误
- 验证数据是否存在
