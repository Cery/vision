## 二、测试执行步骤

### 2.1 本地开发环境测试

#### 步骤1: 启动服务

```bash
# 终端1: 启动Hugo
cd /path/to/vision
hugo server -D --port 1313

# 终端2: 启动Workers
cd cloudflare
wrangler dev --port 8787
```

#### 步骤2: 运行自动化测试

**Node.js版本**:
```bash
cd scripts
node test-full-workflow.js local
```

**PowerShell版本**:
```powershell
cd scripts
.\test-full-workflow.ps1 -Environment local
```

#### 步骤3: 手动测试验证

1. **访问管理后台**: `http://localhost:1313/admin/dashboard.html`
2. **登录测试**: 使用管理员账号登录
3. **功能测试**: 按照测试方案逐一测试各功能

### 2.2 生产环境测试

#### 步骤1: 部署到生产

```bash
# 1. 提交代码
git add .
git commit -m "测试: 全业务流程测试"
git push origin main

# 2. 等待自动部署
# Netlify会自动构建和部署前端
# Cloudflare Workers会自动部署（如果配置了CI/CD）
```

#### 步骤2: 验证部署

```bash
# 检查前端
curl https://www.visndt.com

# 检查API
curl https://api.visndt.com/api/health

# 检查管理后台
curl https://www.visndt.com/admin/dashboard.html
```

#### 步骤3: 运行生产环境测试

**Node.js版本**:
```bash
cd scripts
node test-full-workflow.js production
```

**PowerShell版本**:
```powershell
cd scripts
.\test-full-workflow.ps1 -Environment production `
  -AdminUser "your_username" `
  -AdminPassword "your_password"
```

### 2.3 数据同步测试

#### 步骤1: 创建静态内容

```bash
# 在content/目录创建测试内容
# content/products/vis/test-product.md
# content/news/test-news.md
# content/cases/test-case.md
```

#### 步骤2: 构建静态站点

```bash
hugo --minify
```

#### 步骤3: 检查索引文件

```bash
# 本地
curl http://localhost:1313/data/index.json

# 生产
curl https://www.visndt.com/data/index.json
```

#### 步骤4: 同步到数据库

```bash
# 获取Token
TOKEN=$(curl -X POST https://api.visndt.com/api/admin/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"password"}' \
  | jq -r '.token')

# 同步产品
curl -X POST "https://api.visndt.com/api/admin/import-products?base=https://www.visndt.com/data" \
  -H "Authorization: Bearer $TOKEN"

# 同步新闻
curl -X POST "https://api.visndt.com/api/admin/import-news?base=https://www.visndt.com/data" \
  -H "Authorization: Bearer $TOKEN"

# 同步案例
curl -X POST "https://api.visndt.com/api/admin/import-cases?base=https://www.visndt.com/data" \
  -H "Authorization: Bearer $TOKEN"
```

#### 步骤5: 验证同步结果

```bash
# 检查数据库中的数据
curl "https://api.visndt.com/api/products" | jq '.items | length'
curl "https://api.visndt.com/api/news" | jq '.items | length'
curl "https://api.visndt.com/api/cases" | jq '.items | length'

# 检查前端显示
# 访问产品页面、新闻页面、案例页面
```

## 四、常见问题处理

### 4.1 测试脚本问题

**问题**: 脚本执行失败
**解决**:
1. 检查Node.js/PowerShell版本
2. 检查API地址是否正确
3. 检查网络连接
4. 查看详细错误信息

**问题**: 认证失败
**解决**:
1. 检查管理员账号密码
2. 检查环境变量配置
3. 检查Token是否过期

### 4.2 数据同步问题

**问题**: 同步失败
**解决**:
1. 检查索引文件是否存在
2. 检查索引文件格式是否正确
3. 检查API地址是否正确
4. 查看同步日志

**问题**: 数据不一致
**解决**:
1. 重新同步数据
2. 检查字段映射
3. 手动修复不一致数据

### 4.3 前端显示问题

**问题**: 页面404
**解决**:
1. 检查Hugo构建是否成功
2. 检查路由配置
3. 检查文件是否存在

**问题**: 数据不显示
**解决**:
1. 检查API是否正常
2. 检查数据是否同步
3. 查看浏览器控制台错误
