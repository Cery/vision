#### ✅ 需求撮合系统
**实施内容**:
- ✅ 创建`supplier_tags`表（供应商标签）
- ✅ 实现供应商匹配算法
- ✅ 添加撮合API：`POST /api/admin/match-suppliers`

**匹配算法**:
1. 从需求中提取关键词（标题、分类、标签）
2. 匹配供应商标签和产品分类
3. 计算匹配度分数：
   - 关键词匹配：+10分
   - 公司名匹配：+5分
   - 产品分类匹配：+15分
   - 二级分类匹配：+10分
4. 按分数排序，返回Top 20

**使用方式**:
```javascript
POST /api/admin/match-suppliers
{
  "requirement_id": "REQ-20250120-001"
}
```

**返回示例**:
```json
{
  "matches": [
    {
      "supplier": {
        "supplierId": "SUP-001",
        "company": "XX公司",
        "phone": "138xxxx",
        "email": "xxx@example.com"
      },
      "score": 35,
      "matchedKeywords": ["内窥镜", "检测"]
    }
  ]
}
```

**实施内容**:

- ✅ 实现通知查询API：`GET /api/admin/notifications`
- ⚠️ **仅创建接口结构，不接入实际发送服务**

**通知字段**:
- `notification_id`: 唯一标识
- `type`: 通知类型（email, sms）
- `recipient_type`, `recipient_id`: 收件人类型和ID
- `recipient_email`, `recipient_phone`: 联系方式
- `subject`, `content`: 标题和内容
- `template_id`: 模板ID（可选）
- `status`: 状态（pending - 待管理员手动发送）
- `scheduled_at`, `sent_at`: 计划时间和发送时间

**工作流程**:
1. 管理员创建通知记录（status: pending）
2. 系统记录通知到数据库
3. **管理员通过电话/短信/邮件手动发送**（现阶段）
4. 管理员可标记为已发送（更新status和sent_at）

**使用方式**:
```javascript

{
  "type": "email",
  "recipient_type": "user",
  "recipient_email": "user@example.com",
  "subject": "需求报价通知",

}
```

## 二、数据库Schema更新

### 2.1 新增表结构

#### admin_users (管理员用户表)
```sql
CREATE TABLE admin_users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT UNIQUE,
  username TEXT UNIQUE,
  password_hash TEXT,
  role TEXT DEFAULT 'admin',
  status TEXT DEFAULT 'active',
  last_login_at TEXT,
  created_at TEXT,
  updated_at TEXT
);
```

#### admin_logs (操作日志表)
```sql
CREATE TABLE admin_logs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  log_id TEXT UNIQUE,
  user_id TEXT,
  username TEXT,
  action TEXT,
  module TEXT,
  resource_type TEXT,
  resource_id TEXT,
  details_json TEXT,
  ip_address TEXT,
  user_agent TEXT,
  created_at TEXT
);
```

#### backup_history (备份历史表)
```sql
CREATE TABLE backup_history (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  backup_id TEXT UNIQUE,
  backup_type TEXT,
  backup_file TEXT,
  size INTEGER,
  tables_included TEXT,
  created_by TEXT,
  created_at TEXT
);
```

#### notifications (通知表)
```sql
CREATE TABLE notifications (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  notification_id TEXT UNIQUE,
  type TEXT,
  recipient_type TEXT,
  recipient_id TEXT,
  recipient_email TEXT,
  recipient_phone TEXT,
  subject TEXT,
  content TEXT,
  template_id TEXT,
  status TEXT DEFAULT 'pending',
  scheduled_at TEXT,
  sent_at TEXT,
  error_message TEXT,
  created_at TEXT,
  updated_at TEXT
);
```

#### notification_templates (通知模板表)
```sql
CREATE TABLE notification_templates (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  template_id TEXT UNIQUE,
  name TEXT,
  type TEXT,
  subject TEXT,
  content TEXT,
  variables_json TEXT,
  is_active INTEGER DEFAULT 1,
  created_at TEXT,
  updated_at TEXT
);
```

#### supplier_tags (供应商标签表)
```sql
CREATE TABLE supplier_tags (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  supplier_id TEXT,
  tag TEXT,
  created_at TEXT,
  FOREIGN KEY (supplier_id) REFERENCES suppliers(supplier_id) ON DELETE CASCADE
);
```

### 2.2 表结构扩展

- `suppliers`表：新增`tags_json`和`product_categories_json`字段（用于撮合匹配）
