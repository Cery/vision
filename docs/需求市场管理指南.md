# 需求市场管理指南

本指南面向平台管理员，说明如何在管理页面使用与维护“需求市场”：包括需求方企业信息、需求信息与状态、供应商报价管理，以及常见问题与中文编码处理。

## 管理入口与登录

- 管理页地址：`/management.html`
- API 基址：默认在本地为 `http://localhost:8787`，线上为 `https://api.visndt.com`。
- 可在浏览器控制台手动设置：`localStorage.setItem('API_BASE', 'https://api.visndt.com')`。
- 管理员密钥：在 Worker `wrangler.toml` 中配置的 `ADMIN_KEY`（示例：`admin123456`）。
- 登录步骤：输入管理员密钥后点击“登录”，成功后显示需求、需求方、供应商三个分区。

## 需求管理

- 列表与过滤：支持按关键词、状态、是否开启在线报价、是否公开联系方式过滤；分页浏览。
- 详情与编辑：在列表点击“详情”打开弹窗，支持编辑以下字段：
  - 标题、企业（需求方公司）
  - 状态（公开/隐私/关闭）、进度（发布中/接洽中/已完成）
  - 开启在线报价、公开联系方式（复选）
  - 查看密码（明文）、联系人、联系电话、联系邮箱、部门
  - 公开预览文案（对外展示简述）
- 保存：点击“保存”后将通过管理接口 `PATCH /api/admin/requirements/{RequirementID}` 更新，列表自动刷新。
- 批量设置：在管理页顶部“批量应用”可统一设置全站需求的查看密码、是否开启在线报价、是否公开联系方式（调用 `POST /api/admin/requirements` 的 `applyToAll` 功能）。

## 报价管理

- 查看报价：在需求列表点击“报价”打开弹窗，展示供应商名称/联系人/电话/报价金额/当前状态。
- 修改状态：为每条报价提供状态下拉选择（已提交/审核中/已通过/已拒绝/中标/未中），点击“更新”调用管理接口 `PATCH /api/quotes/{QuoteID}` 修改状态。
- 权限控制：
  - 管理员可查看全部报价。
  - 普通用户需凭需求查看密码或供应商通行密码才能查看相关报价。

## 需求方企业管理

- 列表：按公司名聚合统计需求量，支持搜索筛选。
- 编辑：点击“编辑”在右侧显示编辑器，支持修改公司、联系人、电话、邮箱、是否公开联系方式、通行密码（明文）。
- 保存：调用 `PATCH /api/admin/demanders/{DemanderID}` 更新。

## 供应商管理

- 列表：展示供应商公司名、联系人、电话、邮箱、站点链接等信息；支持搜索与分页。
- 编辑：点击“编辑”显示编辑器，支持修改公司、联系人、电话、邮箱、官网链接、是否公开联系方式、通行密码（明文）。
- 保存：调用 `PATCH /api/admin/suppliers/{SupplierID}` 更新。

## 系统配置

- 管理页提供系统设置保存入口（如默认导出格式、掩码过滤、短信/邮件通知开关等），调用 `/api/admin/system-config` 接口保存。
- 根据运营需要设置与调整。

## 数据安全与访问控制

- 管理接口需携带 `X-Admin-Key` 头。
- 公开需求与隐私需求：
  - 公开需求可直接在前台浏览；隐私/关闭需求需管理员/密码访问。
- 查看密码：用于需求详情及报价的受控访问，可以在需求详情中设置或批量更新。
- 供应商通行密码：用于供应商查看包含联系方式的需求详情与报价列表（由管理员在供应商管理中统一维护）。

## 常见问题（FAQ）

- 404/NotFound：确保请求路径以 `/api/...` 开头；自定义域已在 Cloudflare Worker 的 `routes` 中绑定。
- 跨域 CORS：前端通过 `window.apiFetch` 走统一 `API_BASE`；Worker 已处理 `OPTIONS` 预检与允许头 `Content-Type, X-Admin-Key`。
- 中文乱码：
  - 后端已统一返回 `Content-Type: application/json; charset=utf-8`。
  - 前端页面 `<meta charset="utf-8">` 已配置。
  - Windows 终端可设置：`chcp 65001` 后执行，或在 PowerShell 中执行 `$OutputEncoding = [Console]::OutputEncoding = [System.Text.Encoding]::UTF8`。
- 管理页默认 API：
  - 本地环境默认 `http://localhost:8787`；如本地函数未启动，手动设置为线上 `https://api.visndt.com`。

## 验证与回归测试

- 公共接口：`GET https://api.visndt.com/api/requirements` 返回需求列表。
- 管理需求列表：`GET https://api.visndt.com/api/admin/requirements`（需 `X-Admin-Key`）。
- 需求详情（供应商密码）：`GET https://api.visndt.com/api/requirements/{ID}?supplier_access_password=...` 包含联系方式。
- 报价列表（管理员）：`GET https://api.visndt.com/api/quotes?requirement_id={ID}`。
- 更新报价状态：`PATCH https://api.visndt.com/api/quotes/{QuoteID}`，JSON：`{ "status": "approved" }`。
- 批量更新需求：`POST https://api.visndt.com/api/admin/requirements`，JSON：`{ "applyToAll": true, "allowOpenQuotes": true }`。

## 运维建议

- 定期导出需求与报价数据备份（D1 数据库）。
- 管理员密钥妥善保管，若泄露请立即在 `wrangler.toml` 变更并重新部署。
- 配合站点内容团队，在需求发布周期内及时设置“进度”和“状态”，确保外界认知一致。
