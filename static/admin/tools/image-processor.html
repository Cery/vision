启动Python抓取服务

请先启动Python后端服务来使用真实的网页抓取功能：

🔧 首次设置步骤：
  1. 进入 tools/python-crawler/ 目录
  2. 双击运行 check_python_simple.bat 检查Python环境
  3. 如果Python未安装，运行 install_python.bat 获取安装指导
  4. Python安装完成后，双击运行 start_service.bat
  5. 等待服务启动完成（首次需要安装依赖包）
  6. 点击"检查"按钮确认服务状态
⚡ 快速启动（Python已安装）：
  1. 双击运行 quick_start.bat
  2. 等待服务启动
  3. 点击"检查"按钮确认状态
🔍 故障排除：
  • 如果启动脚本无输出，说明Python未安装或未添加到PATH
  • 运行 check_python_simple.bat 诊断环境问题
  • 查看 Python安装指南.md 获取详细安装说明
