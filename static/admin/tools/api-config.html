使用说明

  1. 访问 OpenRouter平台 注册账号
  2. 在 API密钥页面 创建新的API密钥
  3. 复制密钥并粘贴到上方输入框（已预设密钥）
  4. 点击"保存配置"和"测试连接"
  5. 配置成功后，所有编辑器的AI功能将可用
  6. 支持Claude 3.5 Sonnet、GPT-4、Gemini等多种先进模型
