# 双模式图片管理系统使用指南

## 🎯 概述

双模式图片管理系统为内容编辑器提供了两种图片处理方案：
- **方案A：完全自动化** - 一键处理所有图片
- **方案B：半自动确认** - 手动选择要处理的图片

## 🔧 技术架构

### 核心组件
1. **ImagePathManager** - 智能路径管理器
2. **DualModeImageProcessor** - 双模式图片处理器
3. **Python图片服务** - 后端图片下载服务

### 路径映射规则

```javascript
// 内容类型到路径的映射
{
  'tech-article': {
    staticPath: 'static/images/content/tech-articles',
    publicPath: '/images/content/tech-articles',
    contentPath: 'content/news',
    namePrefix: 'tech'
  },
  'exhibition': {
    staticPath: 'static/images/content/exhibitions',
    publicPath: '/images/content/exhibitions', 
    contentPath: 'content/news',
    namePrefix: 'exhibition'
  },
  'case-study': {
    staticPath: 'static/images/content/case-studies',
    publicPath: '/images/content/case-studies',
    contentPath: 'content/cases', 
    namePrefix: 'case'
  }
}
```

## 📁 文件命名规则

### 自动命名格式
```
{namePrefix}-{contentId}-{index}.{extension}
```

### 示例
- 技术文章：`tech-2025-07-17-工业内窥镜技术-01.jpg`
- 展会信息：`exhibition-2025-07-17-中国国际工业博览会-01.png`
- 应用案例：`case-2025-07-17-航空发动机叶片检测-01.jpg`

## 🚀 使用方法

### 1. 启动图片服务

```bash
cd static/tools/python-crawler
python image_crawler_service.py
```

### 2. 在编辑器中选择处理模式

#### 方案A：完全自动化
- 选择"完全自动化"模式
- 编辑内容，包含图片URL
- 点击"生成Markdown文件"
- 系统自动下载并重命名所有图片

#### 方案B：半自动确认
- 选择"半自动确认"模式
- 编辑内容，包含图片URL
- 点击"生成Markdown文件"
- 在弹出的确认对话框中：
  - 预览所有检测到的图片
  - 选择要处理的图片
  - 可自定义文件名
  - 确认处理

### 3. 处理结果

系统会：
1. 下载选中的图片到对应目录
2. 按规则重命名文件
3. 替换Markdown中的图片路径
4. 生成最终的Markdown文件

## 🎨 编辑器集成

### 技术文章编辑器
```javascript
// 初始化图片处理器
this.imageProcessor = new DualModeImageProcessor({
  mode: 'semi-auto',
  editorType: 'tech-article',
  contentInfo: this.techData
});

// 处理图片
const result = await this.imageProcessor.processImages(content);
```

### 展会编辑器
```javascript
// 配置展会类型
this.imageProcessor.initialize('exhibition', this.exhibitionData);
```

### 应用案例编辑器
```javascript
// 配置案例类型
this.imageProcessor.initialize('case-study', this.caseData);
```

## 🛠️ 自定义配置

### 添加新的内容类型

1. 在 `ImagePathManager` 中添加配置：
```javascript
this.pathConfig['new-type'] = {
  staticPath: 'static/images/content/new-type',
  publicPath: '/images/content/new-type',
  contentPath: 'content/new-type',
  namePrefix: 'new',
  description: '新类型'
};
```

2. 在编辑器中使用：
```javascript
this.imageProcessor.initialize('new-type', contentInfo);
```

### 自定义命名规则

修改 `generateImageFileName` 方法：
```javascript
generateImageFileName(pathConfig, imageIndex, originalUrl, customName) {
  // 自定义命名逻辑
  return customName || `${pathConfig.namePrefix}-custom-${imageIndex}.jpg`;
}
```

## 🔍 故障排除

### 常见问题

1. **图片下载失败**
   - 检查Python服务是否启动
   - 确认图片URL可访问
   - 检查网络连接

2. **路径错误**
   - 确认目标目录权限
   - 检查路径配置是否正确
   - 验证项目根目录设置

3. **文件名冲突**
   - 系统会自动处理重名文件
   - 可使用自定义文件名避免冲突

### 调试模式

启用调试输出：
```javascript
this.imageProcessor = new DualModeImageProcessor({
  mode: 'semi-auto',
  editorType: 'tech-article',
  contentInfo: this.techData,
  debug: true  // 启用调试
});
```

## 📈 性能优化

### 并发控制
- 默认最多同时下载5张图片
- 可在Python服务中调整并发数

### 缓存机制
- 重复图片自动去重
- 本地缓存避免重复下载

### 错误恢复
- 下载失败自动重试
- 网络错误时保持原始URL

## 🎯 最佳实践

1. **图片命名**
   - 使用有意义的文件名
   - 避免特殊字符
   - 保持命名一致性

2. **目录管理**
   - 按日期分组存储
   - 定期清理无用图片
   - 备份重要图片

3. **性能考虑**
   - 优先处理小尺寸图片
   - 批量处理时控制并发数
   - 监控存储空间使用
