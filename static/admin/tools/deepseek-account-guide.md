# DeepSeek API 账户充值指南

## 问题说明
当前DeepSeek API返回"Insufficient Balance"错误，表示账户余额不足。

## 解决步骤

### 1. 登录DeepSeek平台
访问：https://platform.deepseek.com/

### 2. 查看账户余额
- 点击右上角用户头像
- 选择"账户设置"或"Billing"
- 查看当前余额和使用情况

### 3. 充值账户
- 在账户页面找到"充值"或"Add Credits"按钮
- 选择充值金额（建议最少充值$5-10）
- 完成支付流程

### 4. 验证充值
- 充值完成后，返回账户页面确认余额
- 重新测试API连接

## DeepSeek API 定价参考
- 输入Token：约 $0.14 / 1M tokens
- 输出Token：约 $0.28 / 1M tokens
- 一般用途：$5可以支持大量测试和开发使用

## 免费额度说明
- 新用户通常有一定的免费额度
- 免费额度用完后需要充值才能继续使用
- 建议充值少量金额用于开发测试

## 注意事项
1. 使用国际信用卡或PayPal支付
2. 充值后可能需要几分钟生效
3. 建议设置使用限额避免意外消费
