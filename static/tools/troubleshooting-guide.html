Python图片服务问题

图片处理功能不可用

问题描述：图片下载和处理功能无法正常工作。

启动Python服务
  1. 检查Python环境
    python --version
  2. 安装依赖
    pip install flask requests pillow beautifulsoup4
  3. 启动服务
    cd static/tools/python-crawler
    python image_crawler_service.py
  4. 验证服务
    curl http://localhost:5000/api/health
注意：如果端口5000被占用，请修改服务配置或关闭占用端口的程序。

编辑器功能异常

AI功能或图片处理不工作

问题描述：编辑器中的AI创作或图片处理功能无响应。

诊断步骤
  1. 检查浏览器控制台
    • 按F12打开开发者工具
    • 查看Console标签页的错误信息
    • 查看Network标签页的请求状态
  2. 验证服务状态
    • 访问 API配置页面
    • 检查所有服务的状态指示器
    • 运行连接测试
  3. 清除缓存
    • 刷新页面（Ctrl+F5）
    • 清除浏览器缓存
    • 重新加载编辑器

网络连接问题

网络请求失败或超时

问题描述：API请求失败，可能是网络连接或防火墙问题。

检查项目
  1. 网络连接
    • 确认互联网连接正常
    • 测试访问外部网站
    • 检查代理设置
  2. 防火墙设置
    • 检查防火墙是否阻止了API请求
    • 确认端口5000未被阻止
    • 临时关闭防火墙测试
  3. CORS问题
    • 确认浏览器允许跨域请求
    • 检查API服务的CORS配置
    • 使用Chrome的--disable-web-security参数测试
