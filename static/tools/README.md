# Vision NDT 开发工具集

## 📋 概述

这是专为 Vision NDT Hugo 项目设计的开发工具集，提供内容创建、编辑和管理的便捷工具。

## 📁 工具目录结构

```
tools/
├── image-processor.html          # 图片处理工具主页面
├── exhibition-editor.html        # 展会编辑器
├── python-crawler/               # Python图片抓取服务
│   ├── image_crawler_service.py  # 主服务文件
│   ├── requirements.txt          # Python依赖
│   ├── start_service.bat         # 启动脚本
│   ├── test_crawler.py           # 测试脚本
│   ├── README.md                 # 服务说明
│   └── venv/                     # 虚拟环境(自动创建)
└── README.md                     # 本说明文件
```

## 🛠️ 可用工具

### 1. 展会信息编辑器 (exhibition-editor.html)

专业的展会信息编辑工具，支持左右分屏编辑预览模式。

#### 🎯 主要功能
- **左右分屏**：左侧编辑，右侧实时预览
- **Hugo兼容**：完全符合项目的Hugo语法和模板结构
- **智能表单**：动态添加展品分类和参展商信息
- **自动生成**：智能生成文件名和SEO字段
- **一键保存**：直接下载符合规范的Markdown文件
- **🤖 全网自动创作**：基于关键词智能生成展会内容
- **🔗 指定网页获取**：从展会官网提取信息自动填充

#### 📝 使用方法

##### 🔧 三种内容创建模式

**1. 手动编辑模式**
1. 访问：`http://localhost:1313/tools/exhibition-editor.html`
2. 选择"手动编辑"模式
3. 填写展会基本信息（标题、时间、地点等）
4. 添加展品范围和参展商信息
5. 实时查看右侧Markdown预览
6. 点击"保存到本地"下载文件
7. 将下载的`.md`文件放到项目的`content/news/`目录

**2. 🤖 全网自动创作模式**
1. 选择"全网自动创作"模式
2. 输入展会关键词（如：2025年中国国际机床展览会）
3. 选择所属行业（可选，系统会自动识别）
4. 点击"开始自动创作"
5. 系统将基于关键词智能生成完整的展会信息
6. 检查生成内容，根据需要进行调整
7. 保存文件到本地

**3. 🔗 指定网页获取模式**
1. 选择"指定网页获取"模式
2. 输入展会官网或介绍页面的URL
3. 选择内容提取模式（智能提取/完整内容/基本信息）
4. 点击"获取网页内容"
5. 系统将从指定网页提取展会信息并自动填充
6. 检查提取内容，补充完善信息
7. 保存文件到本地

#### 🔧 生成的文件特点
- **完全兼容**：与项目现有展会文件格式完全一致
- **SEO优化**：自动生成标题、描述、关键词
- **图片路径**：使用项目标准的图片路径结构
- **模板布局**：使用`exhibition-universal`布局
- **字段完整**：包含所有必需的YAML前置字段

#### 📊 支持的字段
- 基本信息：标题、摘要、时间、地点、主办方
- 展会规模：周期、面积、参展商数量、观众数量
- 展品范围：支持多个分类，每个分类多个产品
- 往届参展商：企业名称和分类
- 联系信息：电话、邮箱、网站
- SEO字段：自动生成优化的标题、描述、关键词

#### 🤖 智能创作功能

##### 全网自动创作
- **关键词识别**：智能识别展会名称、行业、时间等信息
- **行业模板**：内置10+行业专业模板（航空航天、机械制造、能源电力等）
- **智能填充**：自动生成展会规模、参展商、展品范围等信息
- **地点匹配**：根据行业自动匹配合适的展览中心
- **内容生成**：智能生成展会描述和SEO优化内容

##### 指定网页获取
- **URL解析**：支持主流展会网站内容提取
- **智能识别**：自动识别展会基本信息
- **多种模式**：智能提取、完整内容、基本信息三种模式
- **数据清洗**：自动清理和格式化提取的内容
- **补充完善**：提取后可手动补充和调整信息

#### 🎯 支持的行业模板

### 2. 图片处理工具 (`image-processor.html`)

专业的图片批量处理工具，为展会图片提供完整的处理方案。

#### 🎯 主要功能
- **批量上传**：支持拖拽和多选上传，最大10MB单文件
- **智能压缩**：保持质量的同时减小文件大小
- **格式转换**：支持WebP、JPEG、PNG格式转换
- **尺寸调整**：自动生成封面和缩略图尺寸
- **路径生成**：自动生成Hugo项目路径代码
- **批量下载**：一键下载所有处理后的图片

#### 📝 使用方法
1. 访问：`http://localhost:1313/tools/image-processor.html`
2. 拖拽或点击上传图片文件
3. 设置处理选项（压缩质量、输出格式、尺寸调整等）
4. 点击"开始处理图片"
5. 等待处理完成
6. 下载处理后的图片或复制路径代码
7. 将图片保存到项目的`static/images/news/`目录

#### 🔧 处理选项
- **压缩质量**：高质量(90%)、中等质量(75%)、低质量(60%)
- **输出格式**：保持原格式、JPEG、WebP、PNG
- **尺寸调整**：不调整、封面尺寸(800x600)、缩略图(400x300)、自定义尺寸
- **文件命名**：保持原名、展会格式、时间戳

#### 📊 支持的功能
- **拖拽上传**：直接拖拽图片到上传区域
- **批量处理**：同时处理多张图片
- **实时预览**：上传后立即显示图片预览
- **进度显示**：处理过程中显示详细进度
- **路径生成**：自动生成符合Hugo项目的图片路径代码
- **一键复制**：生成的路径代码可一键复制到剪贴板

#### 🌐 网页图片获取功能

##### 方式一：Python抓取服务（推荐）⭐
**真正的网页抓取功能，无跨域限制**
1. 进入 `python-crawler/` 目录
2. 双击运行 `start_service.bat` 启动Python服务
3. 在工具中选择"网页抓取" → "Python抓取"
4. 输入目标网页URL和过滤条件
5. 点击"开始Python抓取"
6. 选择图片并批量下载ZIP压缩包

**功能特性：**
- ✅ 真实网页抓取，绕过浏览器跨域限制
- ✅ 智能HTML解析，支持多种图片属性
- ✅ 高级过滤：格式、尺寸、数量控制
- ✅ 批量下载：ZIP压缩包，自定义文件名

##### 方式二：图片URL列表
1. 选择"网页抓取" → "图片URL列表"
2. 在文本框中输入图片URL，每行一个
3. 点击"加载图片列表"
4. 选择需要的图片并自定义文件名
5. 点击"保存选中图片"选择保存目录

**示例URL格式：**
```
https://example.com/image1.jpg
https://example.com/image2.png
https://example.com/image3.webp
```

##### 方式三：HTML文件解析
1. 在目标网页右键选择"另存为"
2. 保存类型选择"网页，全部"
3. 在工具中选择"网页抓取" → "HTML文件解析"
4. 上传保存的HTML文件
5. 设置图片过滤条件（格式、最小尺寸等）
6. 工具会自动提取HTML中的所有图片
7. 选择需要的图片并保存

**过滤选项：**
- **图片类型**：所有图片、大图片、仅JPG、仅PNG
- **最小尺寸**：设置最小像素要求
- **自动过滤**：跳过小图标和装饰性图片

#### 💾 智能保存功能
- **现代浏览器**：支持选择保存目录，批量保存到指定文件夹
- **兼容模式**：自动降级为逐个下载到默认下载文件夹
- **自定义命名**：可为每张图片设置自定义文件名
- **批量操作**：支持全选、取消全选、批量重命名

## 📁 文件保存说明

### 文件命名规则
- **展会信息**：`YYYY-MM-DD-展会名称.md`
- **行业资讯**：`YYYY-MM-DD-资讯标题.md`
- **技术文章**：`YYYY-MM-DD-技术主题.md`
- **应用案例**：`YYYY-MM-DD-案例标题.md`

### 保存位置
所有生成的Markdown文件都应保存到项目的 `content/news/` 目录中。

### 模板对应关系
- **行业资讯** → 使用 `layouts/news/industry-news.html` 模板
- **技术文章** → 使用 `layouts/news/tech-article.html` 模板
- **应用案例** → 使用 `layouts/news/case-study.html` 模板
- **展会信息** → 使用默认新闻模板
