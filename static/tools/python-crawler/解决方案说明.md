# Python服务启动问题解决方案

## 🎯 问题总结

**问题现象**：
- 双击 `start_service.bat` 没有输出
- 网页显示"Python服务状态: 离线"
- 检查按钮点击无反应

**根本原因**：
1. Python已安装但未正确添加到PATH环境变量
2. Windows Store Python stub干扰正常Python命令
3. 批处理脚本在PowerShell环境中执行有兼容性问题

## ✅ 解决方案

### 方案一：使用修复后的启动脚本（推荐）

**文件**：`start_service_final.bat`
- 使用检测到的Python完整路径
- 自动安装缺失的依赖包
- 提供详细的启动日志

**使用方法**：
```
双击 start_service_final.bat
```

### 方案二：使用自动检测脚本

**文件**：`start_service_auto.bat`
- 自动检测系统中的Python安装
- 支持多种Python安装方式
- 更通用，适合不同环境

**使用方法**：
```
双击 start_service_auto.bat
```

### 方案三：手动PowerShell命令（高级用户）

```powershell
# 进入服务目录
cd "static\tools\python-crawler"

# 安装依赖（如果需要）
& "C:\Users\Cery\AppData\Local\Programs\Python\Python313\python.exe" -m pip install flask flask-cors requests beautifulsoup4 pillow lxml

# 启动服务
& "C:\Users\Cery\AppData\Local\Programs\Python\Python313\python.exe" image_crawler_service.py
```

## 🔄 日常使用

服务启动成功后，日常使用流程：
1. 双击 `start_service_final.bat` 启动服务
2. 打开 http://localhost:1315/tools/image-processor.html
3. 选择"Python抓取"功能
4. 输入目标网页URL开始抓取
5. 选择图片并批量下载

**注意**：每次重启电脑后需要重新启动Python服务。
